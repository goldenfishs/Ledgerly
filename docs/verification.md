# 测试与验证

本仓库包含后端自动化测试、前端请求上下文测试，以及适用于发布前的浏览器检查清单。测试使用临时数据库、合成用户与文件，AI 和 SMTP 通过模拟服务验证，不需要真实密钥或收件邮箱。

## 运行自动化检查

在仓库根目录，使用已激活的 Python 虚拟环境：

```sh
python -m pip install -r requirements-dev.txt
python -m pytest -q
npm ci --prefix frontend
node --test tests/test_frontend.mjs
npm run format:check --prefix frontend
npm run build --prefix frontend
```

也可以只运行与修改相关的测试，例如：

```sh
python -m pytest -q tests/test_identity.py tests/test_identity_integration.py tests/test_profile.py
```

CI 配置见 [`.github/workflows`](../.github/workflows)。是否通过以对应提交的工作流结果及实际命令退出码为准；本说明不以固定测试数量代替当前结果。

## 自动化覆盖范围

| 用例文件 | 主要范围 |
| --- | --- |
| `test_app.py` | 基础账务、金额精度、分类、账户、审核、权限及会话 |
| `test_ledgers.py` | 多账本隔离、创建切换、成员角色、邀请和迁移 |
| `test_ledger_review.py` | 跨账本访问、角色边界及并发保护的独立回归 |
| `test_invoices.py` | 文件验证、上传去重、原件与预览、识别、版本冲突和回收恢复 |
| `test_identity.py` | 注册策略、SMTP 配置、验证码过期、用途、限流及单次消费 |
| `test_identity_integration.py` | 身份变更与既有数据、账本角色、会话和邮箱登录的集成 |
| `test_profile.py` | 账号与密码修改、邮箱绑定、头像内容及文件访问 |
| `test_frontend.mjs` | 账本请求头、切换时中止请求、迟到响应和会话清理 |

自动化通过不能替代布局检查、真实部署检查或自己的邮件服务连通性检查。

## 隔离浏览器验收

使用单独的数据目录与端口，避免将测试账号、发票和邮件设置写入日常账本。示例：

```sh
STUDIO_DATA_DIR=./tests/artifacts/qa-data python -m uvicorn backend.main:app --host 127.0.0.1 --port 10671
```

先运行前端构建，再打开 [http://localhost:10671](http://localhost:10671)。浏览器直接使用后端提供的构建页面，便于保证页面和 API 使用同一来源。使用单独的浏览器会话，避免同一主机上不同端口的 Cookie 相互影响。

需要联调邮件时，使用本机 SMTP 接收器或受控测试邮箱；验证码与授权码不应进入截图、提交或共享日志。AI 验收可以使用受控的模拟兼容接口，避免上传真实财务资料。

### 账本与账务

- [ ] 首次初始化可创建管理员与第一个账本，后续访问不会重复初始化。
- [ ] 创建第二个账本，切换后账户、分类、流水、发票与统计独立。
- [ ] 生成并复制邀请，未登录可打开，登录后返回邀请，接受后进入正确账本。
- [ ] 过期、撤销及已使用邀请显示正确状态，重复接受不能获得额外权限。
- [ ] 普通成员看不到团队账户余额或其他成员的流水、发票，不能管理系统。
- [ ] 新流水待审核，通过后按分精确影响余额；转账不进入收入或支出统计。
- [ ] 切账、退出或权限变化后，不残留旧账本数据；编辑中离开有相应保护。

### 发票

- [ ] 合成图片和 PDF 可上传、预览，PDF 原件完整保留。
- [ ] 未配置识别服务时可手工填写；识别失败保留原件并可重试。
- [ ] 保存后金额与状态正确，重新打开和刷新仍保留。
- [ ] 相同文件重复上传有明确提示；不同账本不会因相同文件互相泄露记录。
- [ ] 删除进入回收站，恢复后字段与附件仍可访问。

### 账号、注册与系统

- [ ] 仅系统管理员可访问系统设置，账本管理员无法通过直接 URL 绕过。
- [ ] 系统名称同步到侧栏、页面标题、登录、注册及找回页面。
- [ ] 仅邀请、开放、关闭三种注册模式按配置生效，关闭注册不影响已有用户接受邀请。
- [ ] 强制验证时必须邮箱加验证码；未强制时不填邮箱可注册，填邮箱仍需验证。
- [ ] SMTP 保存不会自动发信，留空密码保留旧值，测试按钮使用已保存配置。
- [ ] 公开注册的新账号没有账本权限，仍可使用个人中心。
- [ ] 修改账号和密码验证当前密码；修改密码后旧会话失效。
- [ ] 合成头像上传、刷新及移除正常；邮箱绑定后可用已验证邮箱登录。
- [ ] 密码找回使用正确用途验证码，成功后旧密码与旧会话失效。

### 页面与交互

- [ ] 在桌面和 390px 手机宽度检查账本、流水、系统设置、个人中心及公开账号页面。
- [ ] 没有页面或卡片内部横向溢出，长系统名称与账本名称不撑开布局。
- [ ] 月份选择、跨年翻月、返回本月及筛选正常。
- [ ] 密码显隐和验证码倒计时不会改变输入框的可访问名称。
- [ ] 错误提示清楚，提交期间不能重复操作；键盘可进入表单及关键按钮。
